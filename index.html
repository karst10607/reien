💡 Xbox One / 有線手把「已連線但無震動」5 大硬體與系統排除清單：
  1. Windows 原生驅動測試 (joy.cpl)：按下鍵盤 Win + R，輸入 joy.cpl 並按 Enter。點選 Xbox 手把進入「內容 (Properties)」的測試頁籤，確認 Windows 系統底層能否驅動馬達。
  2. Xbox 配件 (Xbox Accessories)「開啟震動」設定：在微軟商店搜尋並開啟「Xbox 配件」，檢查手把設定設定檔中「開啟震動 (Turn on vibration)」是否被關閉，並同步檢查是否有手把韌體更新 (Firmware Update)。
  3. 電池槽低電量鎖定保護 (Brownout Protection)：Xbox One 手把接 USB 時，若背後電池槽裝著沒電或低電量的乾電池，內部 MCU 會強制切斷兩顆震動馬達的供電以防邏輯電路重啟。請將乾電池取出（純靠 USB 供電）再測試。
  4. USB 供電與傳輸線問題：雙馬達全開瞬間電流需 500mA~800mA，若插在無外接供電的 USB Hub、機殼前置延長埠或劣質充電線（線徑過細導致壓降），會自動靜音馬達。請插在主機板後方原生 USB 埠。
  5. Chrome 核心實驗旗標：可在網址列輸入 chrome://flags/#enable-windows-gaming-input-data-fetcher，切換 Enabled / Disabled 以切換 Windows Gaming Input (WGI) 與標準 XInput 傳輸管線。
